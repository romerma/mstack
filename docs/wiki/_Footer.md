Built on [pstack](https://github.com/cursor/plugins/tree/main/pstack) by [Lauren Tan](https://github.com/poteto) (poteto), MIT.

Transcripts on these pages are written as `$ mstack ...` for a reader running the installed plugin; the binary that produces and re-runs them is the repository's own `./bin/mstack` at the commit that edits the page, never the copy on `PATH` — `mstack version` prints which copy is running.
